Game Mode — DLavie RPG

Aktifkan sistem RPG penuh "Dunia Aethoria" langsung di WhatsApp. Pemain bisa membuat karakter, bertualang, dan bersaing di leaderboard.

  • ✅ 5 kelas karakter
  • ✅ Story Mode (3+ chapter)
  • ✅ Exploration (4 zona)
  • ✅ Classic Hunt (7 monster)
  • ✅ PVP Battle Arena
  • ✅ Leaderboard global
  • ⚠️ Multi-bot control: terbatas

⚠️ Catatan Perubahan Mode

  • • Perubahan mode berlaku langsung tanpa restart bot
  • • Saat Game Mode aktif, perintah !play akan mengarahkan ke RPG
  • • Semua data pemain RPG tersimpan di database dan tidak hilang saat mode diubah
  • • Bot yang sudah terhubung tetap online saat mode berubah
