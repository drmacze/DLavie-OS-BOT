FAQ

Apa itu token?

Token adalah "bahan bakar" untuk fitur DLavie OS. Command sederhana hanya butuh 1 token, fitur AI membutuhkan lebih banyak.

Apakah token expired?

Token tidak expired. Token yang kamu beli akan tetap ada sampai digunakan. Token gratis bulanan akan di-reset di awal bulan.

Apa itu sistem antrian?

Untuk melindungi nomor bot dari ban WhatsApp, user Free & Starter masuk antrian. Pro & Enterprise bypass antrian dan langsung diproses.

Bisakah saya upgrade kapan saja?

Ya! Hubungi admin via WhatsApp dengan bukti pembayaran untuk upgrade plan kamu.

Berapa bot yang bisa dihubungkan?

Free: 1 bot, Starter: 3 bot, Pro: 10 bot, Enterprise: unlimited. Setiap bot mendapat access key unik dan panel kontrol privat.
