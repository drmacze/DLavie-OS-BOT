DLAVIE OS — ADVANCED FEATURE ROADMAP UNTUK REPLIT AGENT

TUJUAN:
Kembangkan DLavie OS menjadi WhatsApp Bot Operating System, bukan sekadar bot WhatsApp biasa. Sistem harus mendukung multi-bot control, customization, AI operator, plugin marketplace, recovery engine, payment, dashboard panel, dan automation.

ATURAN WAJIB:
1. Jangan membuat ulang project dari nol.
2. Jangan membuat command/plugin duplikat.
3. Perbaiki file existing jika fitur sudah ada.
4. Jangan hapus session WhatsApp/auth tanpa konfirmasi.
5. Jangan commit .env/API key/session/logs.
6. Buat backup/checkpoint sebelum perubahan besar.
7. Jalankan safety check setelah patch.
8. Pastikan fitur tetap kompatibel dengan bot WhatsApp + web panel.
