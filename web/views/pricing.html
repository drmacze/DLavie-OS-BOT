FAQ

Apa itu Token?

Token adalah "bahan bakar" untuk menjalankan fitur DLavie OS. Setiap command menggunakan token. Semua plan dapat 100 token gratis tiap 10 menit secara otomatis.

Bisa upgrade/downgrade kapan saja?

Ya! Upgrade ke plan yang lebih tinggi kapan saja. Sisa token tidak hangus saat upgrade.

Pembayaran via apa saja?

Pembayaran via QRIS (semua bank & e-wallet: GoPay, OVO, Dana, ShopeePay, BCA, Mandiri, BNI, BRI, dll). Transfer manual juga bisa.

Berapa lama token ditambahkan?

Maksimal 1×24 jam kerja setelah bukti transfer diverifikasi. Biasanya dalam 1-2 jam. Kamu dapat notifikasi WhatsApp saat token ditambahkan.
