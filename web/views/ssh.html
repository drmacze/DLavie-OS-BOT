🔌 Koneksi Remote

Hubungkan ke server SSH, VPS, atau host remote kamu.

⚠️ Note: Koneksi SSH berjalan melalui server DLavie OS. Password tidak disimpan secara permanen.

⚠️ RDP & VNC menggunakan protokol desktop yang tidak bisa di-embed langsung di browser standar.

Opsi yang tersedia:

🖥️
Apache Guacamole

Web-based RDP/VNC gateway. Perlu install sendiri.

🔐
Via SSH Tunnel

Forward port RDP melalui SSH tunnel dari terminal.

ssh -L 3389:localhost:3389 user@host
💡 Gunakan tab SSH Terminal untuk mengakses server dan menjalankan perintah remote.
